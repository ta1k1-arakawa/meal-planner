# 食品・レシピの初期データ

参照資料：文部科学省「日本食品標準成分表2020年版（八訂）」
https://www.mext.go.jp/a_menu/syokuhinseibun/mext_01110.html
食品成分データベース： https://fooddb.mext.go.jp/

シードの値はこの食品分類をもとにした参考・概算値です。厳密な栄養分析やブランド固有の保証値ではありません。`food_code` は `mext2020:<食品名>` というアプリ内の参照キーで、公式の数字の食品番号を装った値ではありません。部位・製品・加熱・可食部で値が変わるため、実運用前に使用する食品に合わせて参照値を見直してください。

`ingredients` は100 gあたりの kcal / たんぱく質、参照元、食品分類キー、raw / cooked / ready を保持します。初期食材はgで管理し、mlを使う食材を追加する場合はその100 mlあたりの栄養を登録します。mlをgとみなす暗黙の換算はしません。個・丁の表示換算は概算で、係数を編集できます。

料理の栄養は `量 × 100単位あたりの参照値 / 100` の合計です。計画時も実使用量の記録時も同じ式を使います。完了時の食材名・単位・量・栄養・参照元と料理のスナップショットは変更できません。訂正は別のスナップショットを保存し、日別集計では最新の訂正値を使用します。

30件のカタログは5種類の主材料と6種類の調理法の組み合わせです。1人分の量を固定し、炊飯済みまたは冷凍のご飯350 gを含みます。炊飯時間は含まれず、この前提は料理の手順とUIに明記しています。食材の下処理・調理は20〜25分を想定した推定です。実機調理による検証済みという意味ではありません。

レシピ検索は栄養の目標値をソフト制約として評価します。850〜1,050 kcal・たんぱく質35 g以上の推奨範囲に必ず収まることは保証しません。時間・設備・登録済みアレルゲン・除外食材はハード制約です。商品を使う際はラベルのアレルゲンも確認してください。

就寝前シェイクの120 kcal / P24 gは未設定ブランドの初期推定値として明記しています。既定プリセットは確認済み摂取へ計上しません。昼食・間食の未記録は「未確認」のままです。
